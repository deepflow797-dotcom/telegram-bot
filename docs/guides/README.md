## معنى الألوان في شجرة الواجهة

- 🟢 **أخضر** — موجود في النسخة المنشورة الآن.
- 🟠 **برتقالي** — مقترح أو ناقص، يحتاج تنفيذاً.
- 🔴 **أحمر** — طلبه العميل ولم يُنفّذ بعد (المقدّم + الاشتراكات).

الأرقام في الشجرة هي المسار: `1` قسم ← `1.2` شاشة ← `1.2.3` خطوة ← `1.2.3.1` حقل.

## توليد الدليل من جديد

الدليل مبني بسكربت مرفق مع المشروع (لا يحتاج أي خدمة خارجية):

```bash
pip install reportlab arabic-reshaper python-bidi
python scripts/build_guide.py            # يكتب docs/guides/bot-guide-ar.pdf
```

* الخط المستخدم: DejaVu Sans (أو Noto Naskh Arabic إن وُجد).
* السكربت يشكّل الحروف العربية ويرتّب الاتجاه (RTL) قبل الرسم، ويلفّ الأسطر منطقياً
  حتى تبقى ترتيب الأسطر صحيحاً، ويحوّل `*bold*`/الوسوم إلى تنسيق التقرير.
* أي إيموجي أو علامات تنصيص زاوية تُحذف تلقائياً لأنها بلا رسم في الخطوط المتاحة.
* لتغيير النصوص: عدّل `build_story()` داخل السكربت ثم أعد التوليد.
